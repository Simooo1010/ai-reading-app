# Playbook kit

Copy the contents of this folder to the root of a new repo, keeping the layout:

```
CLAUDE.md                        # rules Claude reads every turn (fill the <…>)
SETUP-FOR-OWNER.md               # steps only you can do
docs/WORKFLOW.md                 # the method
docs/SPEC.template.md            # Claude turns it into docs/SPEC.md
docs/HOW-TO-WORK-WITH-CLAUDE.md  # your side + ready prompts
```

Then send the kick-off prompt from `docs/HOW-TO-WORK-WITH-CLAUDE.md` §4. This README is not needed in the new repo.
